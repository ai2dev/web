3. 진단 통신 모니터

💡 실행 안내 (교육용 팁):
  • 브라우저 지원: Chrome, Edge 또는 Android Chrome 등 Web Bluetooth API를 지원하는 최신 브라우저가 필요합니다.
  • 보안 요구사항: Web Bluetooth는 브라우저 보안 규정에 따라 https:// 도메인이나 http://localhost 환경에서만 동작합니다.
  • Zoe Ph2 식별자: Zoe Ph1(1세대)은 계기판 DID가 0206이지만, Zoe Ph2(2세대 ZE50)는 0207을 사용합니다.
